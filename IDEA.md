# Project Idea

This is for an iOS application that uses ACP (Agent Communication Protocol) over
SSH or MOSH, providing a user interface for the agent that runs on the user's
desktop or cloud computer system. In order to fulfill this goal, agent harnesses
need to be shipped with the iOS application, such that if the remote is a macOS
system running AArch64, a binary harness can be sent; if the remote is a Linux
system running x86, the same can be done.
